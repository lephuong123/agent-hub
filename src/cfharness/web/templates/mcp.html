Danh sách đọc thẳng từ cấu hình claude (.claude.json) của từng tài khoản. Mọi agent tự động dùng mọi MCP server của tài khoản Claude đang chạy run — hub không gán, không lọc tool.

Cách thêm MCP server
  • Chạy trong terminal của máy chạy hub: claude mcp add <tên> … (vd claude mcp add --transport http <tên> <url>, hoặc claude mcp add <tên> -- <lệnh> <tham số>).
  • Tài khoản không phải mặc định: thêm CLAUDE_CONFIG_DIR=<thư mục> trước lệnh — thư mục cấu hình của tài khoản ghi ở đầu mỗi nhóm bên dưới.
  • Server cần đăng nhập (OAuth): chạy claude mcp login <tên>, hoặc mở claude rồi gõ /mcp.
  • Connector claude.ai bật ở claude.ai và ở Cài đặt › Tài khoản AI.
