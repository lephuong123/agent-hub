## 1. Đã làm

### `agent-hub top` (FR-UI-01, 09) — `tui/app.py`, `tui/model.py`, RPC `tui.snapshot`
- Header: số agent, run đang chạy/chờ slot/tối đa, **thao tác phá huỷ chờ người (nền đỏ, thời gian chờ lâu nhất)**, số
  event `learning.*` hôm nay (M4 sẽ có ý nghĩa đầy đủ), $ và token hôm nay, rate limit, ESTOP, auth block, phiên bản CLI
  (+ "chưa kiểm!" khi ngoài `tested_versions`).
- Bảng `ID, NAME, TEAM (từ team_members của M3), STATUS (●working ◐waiting ⏸waiting_human ○idle ✖error ‖paused), TASK
  (tiêu đề task M3 hoặc dòng đầu prompt), LAST TOOL (… đang chạy / thời lượng / bao lâu trước), T, TOK, $`.
  `waiting_human` suy từ approval `waiting_human` hoặc run `waiting_human`. Sắp xếp `o` (trạng thái/$/thời gian), lọc `/`,
  lọc team `g`, chi tiết dòng chọn (approval đang chờ: thao tác, luật khớp, lý do, thời gian chờ).
- Dữ liệu: `tui.snapshot` mỗi 1 s (một RPC, ~4–6 ms) + vẽ lại mỗi 0.5 s + áp NGAY event firehose (`events.subscribe`
  mức summary, không delta) vào ô của dòng. Firehose bị ngắt (`slow_consumer`, daemon restart) → tự đăng ký lại từ seq
  cuối, không trùng.
- Thao tác: `Enter` attach · `a` cho phép · `d` từ chối (ghi chú) · `N` báo nhầm (allow + note `[false_positive]`) ·
  `s` steer · `x` stop (xác nhận) · `X` stop ngay · `T` takeover · `n`/`e`/`Del` tạo/sửa/xoá mềm agent (form có template,
  model, permission mode, ngân sách, MCP từ `mcp.list`) · `t` Tasks · `l` Learnings · `E` ESTOP · `q`.
  Mọi lời gọi thay đổi trạng thái gửi `_audit {channel: "tui"}` → audit ghi đúng kênh.

### Attach/detach + replay (FR-UI-02, 03) — `AttachScreen`
- Nạp TOÀN BỘ event đã ghi của run từ DB (`run.get events`), rồi `events.subscribe {run_id, since_seq = seq lớn nhất
  của epoch hiện tại, epoch, level: detail}` → ring buffer bù phần sau đó (kể cả delta token) rồi live; khử trùng
  theo (epoch, seq). `message.complete` thay khối chữ đã stream bằng delta (không lặp chữ).
- Transcript: prompt, `run.started` (model, CLI, permission, MCP), suy nghĩ thu gọn (`r` mở), dòng tool
  `┊ tên (args) (2.1s)` cập nhật tại chỗ, kết quả rút gọn, **diff inline cho Edit/MultiEdit/Write**, subagent, approval
  (banner + `a`/`d`), steer (`user.message`) + `steer.ack`, kết thúc run (outcome, $, lượt — gồm `crashed` của M3).
- Esc/thoát app chỉ đóng kết nối subscribe; run không bị ảnh hưởng (test + bench).

### Steer (FR-RT-06, spike A-02) — `steer.py`, `runtime/claude_cli.py`, `runtime/fake.py`, `claude_adapter.py`
- `run.steer {id: run|agent, text}` → ghi một dòng user stream-json vào stdin → event `user.message {text (đã che),
  by, channel}` (source tui/cli/mcp) + `runs.steer_count`. Adapter: tin `isReplay` #1 = prompt (bỏ qua), các tin sau →
  `steer.ack` (CLI phát lại đúng lúc tin vào ngữ cảnh).
- Giữ hành vi M0 "đóng stdin sau `result`": run đã qua `result`/không chạy → `Conflict` gợi ý `run continue`.
  Ngoại lệ có chủ đích: nếu còn tin steer CHƯA được phát lại khi `result` tới (gửi sát cuối lượt), runtime giữ stdin
  mở để CLI chạy tin đó thành lượt mới (spike "twoturns"), rồi đóng; phòng hờ `runtime.claude.steer_ack_grace_s` (30 s).
- CLI: `agent-hub steer <run|agent> "…" [--wait-ack]`, `agent-hub run steer <run> "…"`.

### Template (FR-AG-07) — `templates/*.yaml`
`researcher` (Read/Grep/Glob/WebSearch/WebFetch), `coder` (acceptEdits), `reviewer` (**plan**, Read/Grep/Glob),
`ops` (haiku, Bash+đọc, thao tác phá huỷ qua guard). SOUL tiếng Anh. `agent create <id> --template <t> [cờ ghi đè]`,
`agent-hub template list|show`, RPC `agent.create_from_template`; form TUI có ô template.

### Takeover (FR-UI-10) — `tui/takeover.py`
`agent-hub takeover <run|agent> [--print] [--record]`, phím `T`: run phải đã dừng; hub sinh `settings.json`/`mcp.json`
(0600) của agent ở `agents/<id>/runtime/takeover-<run>/`, chạy `claude --resume <session>` TƯƠNG TÁC trong cwd của run
với `--setting-sources "" --settings --strict-mcp-config --mcp-config --append-system-prompt <SOUL> --model` + tool_policy
(bỏ `bypassPermissions`), loại env `env_strip`. Khi thoát: Run `kind=human_takeover` (`takeover_of_run_id`, cùng session),
event `run.takeover`, xoá file runtime. TUI trong terminal thật dùng `App.suspend()`; không có TTY → hiện lệnh để chạy tay.

### Tab Tasks (FR-UI-07) — `TasksScreen` trên `task.list|get|create` của M3
Đếm theo trạng thái kiểu kanban ở header, bảng sắp theo running→review→ready→blocked→todo→triage (ẩn done, `f`),
cột lý do chờ (`wait_reason`/`block_reason`), chi tiết: cha/con, 3 comment cuối, run; `Enter` attach run hiện tại;
`c` tạo nhanh `<agent>: <tiêu đề>` / `team:<id>: <tiêu đề>`. Daemon không có `task.*` → thông báo thay vì lỗi.

## 3. Nghiệm thu thật (claude 2.1.302, haiku, HUB_HOME tạm trong scratch, tổng **≈ $0.0056** cho 2 lần chạy)
Script: daemon thật + `TopApp` headless (Pilot) kết nối socket; 3 agent tạo từ template `ops`, `coder`, `researcher`
(ghi đè `model=haiku`, `max_budget_usd_per_run=0.3`):
- Cả 3 dòng lên `● working` với LAST TOOL (`Bash`, `Bash`, `Glob`) và TOK tăng (7.3k/19.3k/6.9k) trong ~2 s — xem
  `docs/screenshots/m2/09-real-3-agents.svg`.
- **Steer** run ops khi `sleep 12` đang chạy (qua `app.steer` = phím `s`): `user.message` → `steer.ack` → CLI chạy thêm
  `echo steer-received`, trả lời có PINEAPPLE; MỘT `result`, 3 lượt, `completed`, `steer_count=1`.
- **Stop** run coder (`sleep 40`) qua `app.stop_run` (= `x`): `cancelled`.
- **Đóng TUI** ngay sau đó (2.1 s sau khi submit): run ops và researcher vẫn `completed`.
- Chi phí lần 1 $0.00395, lần 2 $0.00167.

## 4. Lệch BRD / quyết định
- Event steer: BRD nói `steer.sent`; dùng `user.message` (theo yêu cầu M2 và demo) + `steer.ack`.
- `N` "báo nhầm": chưa có cột riêng trong `approval_requests` → allow + `note="[false_positive] …"` (tinh chỉnh bộ phân loại
  NFR-31 đọc từ note). Thêm cột là việc của luồng an toàn.
- Takeover không gắn hook guard/hub-guard (người đang tương tác tự duyệt qua prompt quyền của Claude Code); system prompt
  vẫn là khối hub (câu "non-interactively" không còn đúng hoàn toàn khi takeover — chấp nhận).
- Ô `ctx%` ở thanh trạng thái attach là ƯỚC LƯỢNG (token run / 200k), chưa lấy `contextWindow` thật.
- Cây subagent: chỉ hiện dòng `⤷` của tool/subagent trong transcript, chưa có cây riêng.
- "học hôm nay" = số event `learning.*` hôm nay (M1 chỉ có `learning.signal`); M4 sẽ thay bằng số thay đổi tự áp dụng.

## 5. Việc còn dở
- Tab Learnings (FR-UI-06) chỉ là chỗ trống — M4.
- Tool MCP `hub_steer` (FR-MS) chưa thêm (MCP server thuộc M1-A/M3); RPC `run.steer` đã sẵn. Comment `--steer` của M3
  (`task.comment`) đã gọi được `run.steer`.
- Tab Tasks: chưa có xem DAG dạng cây, chưa sửa/chặn/thử lại task từ TUI (dùng CLI `task …` của M3).
- Takeover: chưa có cờ `--fork-session` để không ghi tiếp vào session gốc; chưa thu Signal `edit_output`.
- Steer qua `input_format: text` không hỗ trợ (runtime báo rõ); phương án dự phòng interrupt + resume của BRD chưa làm
  vì A-02 đã xác nhận.
- Bench đo CPU TUI cùng tiến trình với vòng đo — số thật của TUI riêng sẽ thấp hơn.
