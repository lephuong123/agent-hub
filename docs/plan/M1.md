## File dùng chung — chỉ THÊM, đọc lại ngay trước khi sửa, sửa nhỏ
- `daemon.py` (bảng method RPC), `cli.py` (subcommand), `events.py` (`EVENT_LEVELS`), `store.py` (`MIGRATIONS`), `config.py` (`DEFAULTS`), `hub.py` (nối service), `AGENTS.md` (thêm mục của mình).
- Namespace RPC: A dùng `mcp.*`, `secret.*`, `audit.*`, `feedback.*`; B dùng `approval.*`, `guard.*`, `notify.*`, `run.resume`, `run.continue`.
- Namespace config: A `mcp.*`, `secrets.*`, `mcp_server.*`; B `guard.*`, `approval.*`, `notify.*`, `recovery.*`.
- **Migration**: A = phần tử thứ 3 (user_version 3), B = phần tử thứ 4. Ai thêm trước mà vị trí kia chưa có thì chèn migration giữ chỗ `"-- reserved for M1-A"`/`"-- reserved for M1-B"`; người kia THAY chỗ giữ đó (được phép vì chưa phát hành).

## Hợp đồng giữa A và B
1. **Cấu hình MCP của agent khi chạy**: A cung cấp `mcp_client.build_agent_mcp_servers(agent) -> dict[str, dict]` (dạng `mcpServers` cho `--mcp-config`, đã thay secret). B (sở hữu `claude_cli.py`) gộp thêm entry `hub-guard` rồi ghi `runtime/mcp.json`. Trước khi A xong, B dùng hàm tạm trả `{}` nếu import lỗi.
2. **Tool ghi / audit**: A cung cấp `audit.record(kind, agent_id, run_id, data)` và phát event `tool.write` cho tool không `readOnlyHint`. B gọi `audit.record` cho mọi quyết định guard/approval (nếu chưa có thì tự viết hàm tạm cùng chữ ký trong `guard/`, A thay sau).
3. **Phân loại MCP phá huỷ**: A lưu annotations (`readOnlyHint`, `destructiveHint`, tên, mô tả) khi probe server; B đọc qua `mcp_client.tool_annotations(server, tool) -> dict | None` để phân loại (FR-SG-02 dòng MCP).
4. **Phê duyệt từ MCP server**: tool `hub_open_requests`, `hub_approve`, `hub_deny` của A chỉ gọi RPC `approval.list|approve|deny` của B. Không tự cài logic duyệt.
5. **Feedback**: `hub_feedback` (A) ghi bảng `signals` trong migration của A.
